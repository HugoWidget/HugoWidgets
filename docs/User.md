## 1. 项目简介

HugoWidgets 是**帮助广大电教委对希沃功能进行增强与补充**的桌面工具，也是 [HugoProgs](https://github.com/HugoWidget/HugoProgs) 的**含 UI 版本**：与 HugoProgs 功能类似，但提供更友好的操作方式——不再需要记忆菜单命令，而是通过菜单栏与多标签页界面完成操作。

技术形态：Qt6 ，基于 WidgetExplorer 插件框架构建，所有希沃相关能力来自核心库 [HugoUtils](https://github.com/HugoWidget/HugoUtils)。

> 两者共用同一套底层能力，可按需使用。

## 2. 获取与安装

推荐使用 [HugoSetup](https://github.com/HugoWidget/HugoSetup) 提供的 `HugoWidgets-bundle`，其中包含 HugoWidgets 本体与 `PyExplorer`（图形文件管理器）。

也可以自行编译：见 [HugoWidgets 开发者文档](./Developer.md) 的构建章节。

安装方式为**绿色免安装**：解压到固定目录（建议路径不含中文与空格），保证主程序、Qt6 运行库与插件目录的相对位置不变即可。

## 3. 快速上手

1. 解压 bundle 到固定目录。
2. 右键主程序 → **以管理员身份运行**。
3. 程序加载插件并显示主界面；若可用的主界面插件不止一个，会先弹出选择对话框，请选择要使用的主界面。
4. 在菜单栏或主页中点击功能按钮，对应功能会以**标签页**形式打开；可同时打开多个功能页。
5. 关闭标签页即关闭该功能页，主窗口保持运行。

## 4. 进阶：命令行与非界面模式

主界面插件支持以下命令行参数，便于脚本化调用或排障：

```text
HugoWidgets.exe --function <功能ID> --command <命令> [--arg 键=值]... [--no-gui]
```

| 参数                  | 说明                                               |
| --------------------- | -------------------------------------------------- |
| `--function <功能ID>` | 指定要操作的功能页（由各功能页自身的 `id()` 决定） |
| `--command <命令>`    | 指定要在该功能页上执行的命令                       |
| `--arg <键>=<值>`     | 传入命令参数，可重复多次                           |
| `--no-gui`            | 执行完命令后直接退出，不显示界面                   |

说明：

- 是否支持非界面执行取决于**具体功能页的实现**。
- 未指定 `--no-gui` 时，界面会正常显示，命令在界面初始化后执行。

## 5. 已知限制

- 功能覆盖范围小于 HugoProgs：锁屏、屏保、DLL 注入、WinPE、日志管理、希沃安装/卸载等尚未提供图形界面。
- 不支持 `.hps` 脚本；批量操作请使用 HugoProgs。
- 部分功能仅支持单一实现路径（如冰点仅提供 API/驱动/空实现三种模式，未包含 Hook/Disk/File 等方案）。
